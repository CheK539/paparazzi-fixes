# Русский

## Описание

Набор исправлений для игры **«Папарацци. Охота за сенсацией»** от Alawar для запуска на Windows 10/11. Это не полная игра, требуется установленная оригинальная версия.

## Как установить

1. Закройте игру.
2. Сделайте резервную копию папки игры или заменяемых файлов.
3. Скачайте [архив с исправлениями](RELEASE_DOWNLOAD_URL).
4. Распакуйте содержимое архива **в папку установленной игры**, где находится
   `Paparazzi.exe`, с заменой существующих файлов.
5. Запустите **`Paparazzi_no_drm.exe`**. Для запуска через прежний лаунчер
   можно по-прежнему использовать `Paparazzi.exe`.

## Что исправлено

- Исправлена работа с Unicode-путями, в том числе с кириллицей в имени папки игры.
- Исправлена загрузка игровых данных, из-за которой могли отсутствовать задания,
  появляться `0/0` и `$undefined`, а фотографии не засчитываться.
- Исправлены выход из игры через подтверждение и загрузка логотипа разработчика.
- Внесены исправления полноэкранного режима, масштабирования и его переключателя в настройках.
- Добавлен `Paparazzi_no_drm.exe` для запуска игры без оригинального лаунчера.

## Скачать

**[Скачать архив с исправлениями](RELEASE_DOWNLOAD_URL)**

## Как отменить изменения

Восстановите заменённые файлы из своей резервной копии, удалите `Paparazzi_no_drm.exe`.

# English

## Description

A collection of fixes for Alawar's **«Папарацци. Охота за сенсацией» (Paparazzi)**
to run on Windows 10/11. This is not the full game; an existing installation of
the original game is required. These fixes were prepared for the Russian release.

## Installation

1. Close the game.
2. Back up the game folder or the files that will be replaced.
3. Download the [fixes archive](RELEASE_DOWNLOAD_URL).
4. Extract the contents **into the game's installation folder**, where
   `Paparazzi.exe` is located, and overwrite the existing files.
5. Run **`Paparazzi_no_drm.exe`**. To use the original launcher instead,
   you can still run `Paparazzi.exe`.

## Fixes

- Fixed Unicode path handling, including Cyrillic characters in the game folder name.
- Fixed game data loading issues that could cause missing objectives,
  `0/0` and `$undefined` values, and photographs not being counted.
- Fixed quitting through the confirmation dialog and loading the developer logo.
- Applied fixes to fullscreen mode, scaling, and the fullscreen toggle in settings.
- Added `Paparazzi_no_drm.exe` to launch the game without the original launcher.

## Download

**[Download the fixes archive](RELEASE_DOWNLOAD_URL)**

## Uninstall

Restore the replaced files from your backup and delete `Paparazzi_no_drm.exe`.
